# Bike Rental Management System

## Overview

The Bike Rental Management System is a web-based application developed using JSP, MySQL, HTML, CSS, and JavaScript. The system is designed to simplify the process of renting bikes by allowing customers to browse available bikes, make bookings, and complete payments online while enabling administrators to manage bikes, repairs, bookings, and payment records efficiently.

## Features

### Customer Features

* User Registration and Login
* View Available Bikes
* Book Bikes Online
* Select Pickup and Drop-off Dates
* Calculate Rental Charges
* Make Online Payments
* View Booking History

### Admin Features

* Manage Customer Accounts
* Add, Update, and Remove Bikes
* Track Bike Availability
* Manage Repair Records
* Monitor Bookings and Payments
* Generate Rental Reports

### Repair Management

* Report Bike Issues
* Track Repair Status
* Record Repair Costs
* Maintain Bike Service History

## Technology Stack

* Frontend: HTML, CSS, JavaScript
* Backend: JSP (Java Server Pages)
* Database: MySQL
* Server: Apache Tomcat / GlassFish
* IDE: NetBeans

## Database Tables

* User Management
* Bikes
* Pickup Bookings
* Payments
* Customer Payments
* Repair Management

## Project Workflow

1. User registers and logs in.
2. Customer browses available bikes.
3. Customer selects rental dates.
4. Rental cost is calculated automatically.
5. Customer completes payment.
6. Booking is confirmed.
7. Administrator manages bikes, repairs, and payment records.
